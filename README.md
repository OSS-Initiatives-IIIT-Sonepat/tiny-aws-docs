# tiny-aws docs

Comparison docs for [tiny-aws](https://github.com/OSS-Initiatives-IIIT-Sonepat/tiny-aws) — a self-hosted mini-cloud built by students at IIIT Sonepat.

## What's here

**AWS vs tiny-aws** — How EC2, S3, SQS, SNS, Lambda, VPC, IAM, and ELB compare between the real AWS and tiny-aws's ~8,500 line implementation.

**Coolify vs tiny-aws** — Two very different answers to "I don't want to pay AWS." One is a polished production PaaS (Coolify). The other is an educational infrastructure platform (tiny-aws).

## Running locally

```bash
npm install
npm run dev
```
